# Техническая рецензия на лабораторную работу №2

## Вердикт

Работа готова с одним ограничением: на малом датасете абсолютный RSS чанкового
режима не ниже полного, поэтому ограничение памяти подтверждено отдельной
потоковой проверкой.

## Проверено

- Присутствуют отчёт, метрики, модель, журналы негативных проверок и манифест.
- Хеш модели совпадает с `model_manifest.json`.
- Полный и чанковый режимы имеют MLflow run ID и 95-процентные интервалы.
- Повторный запуск при зерне 42 дал расхождение предсказаний `0.0`.
- Расхождение RMSE между режимами `0.000000694301` меньше допуска `0.005`.
- Test-часть не участвует в подборе модели.
- Три ошибочные конфигурации отклонены.
- Масштабирование на всех данных обнаружено как утечка.
- Поток до 44 200 строк обрабатывается чанками не более 64 строк.

## Рекомендация

Для большого датасета измерять RSS каждого режима в отдельном процессе, чтобы
исключить базовую память интерпретатора и MLflow.
